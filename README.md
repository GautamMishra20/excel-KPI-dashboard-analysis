# Excel KPI Dashboard – Business Performance Analysis

## 📌 Project Overview
This project demonstrates end-to-end data analysis and dashboard creation using Microsoft Excel.
The objective is to transform raw business data into actionable insights using Key Performance Indicators (KPIs) and an interactive dashboard.

---

## 🎯 Business Objective
- Monitor overall business performance through KPIs
- Track sales and profitability trends
- Support management decision-making with a single-page dashboard

---

## 📊 KPIs Tracked
- Total Sales
- Total Profit
- Profit Margin (%)
- Number of Orders
- Average Order Value (AOV)

---

## 🧰 Tools & Techniques Used
- Microsoft Excel
- Data Cleaning and Structuring
- Excel Formulas (SUMIFS, COUNTIFS, IF)
- Pivot Tables and Pivot Charts
- Slicers and Filters
- Conditional Formatting
- Dashboard Design Best Practices

---

## 📈 Dashboard Features
- Centralized KPI view for quick performance tracking
- Interactive filters for dynamic analysis
- Trend analysis for monitoring business growth
- Clean and business-ready dashboard layout

## 🔍 Key Business Insights
- Business performance varies across different time periods
- Certain segments contribute higher revenue but comparatively lower margins
- KPI tracking helps identify performance gaps quickly

The dataset includes:

This project showcases practical Excel skills required for Data Analyst and Business Analyst roles, including KPI definition, dashboard creation, and business insight generation.
